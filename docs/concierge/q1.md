### Q: How do I load variables from a .env file without overwriting environment variables that are already set?

Call `load_dotenv()`. It defaults to `override=False`, so variables already in `os.environ` are kept and only missing ones are set from `.env`. You can pass `override=False` explicitly to make that clear. With the CLI, use `dotenv run --no-override <cmd>`. Interpolation like `${BASE}` also prefers the existing environment value when override is off.

```python
import os
from dotenv import load_dotenv

os.environ["A"] = "from_env"          # already set
load_dotenv(".env", override=False)   # .env containing A=from_file, B=new
print(os.environ["A"])  # from_env (kept)
print(os.environ.get("B"))  # new (added)
```

### Q: Can python-dotenv load configuration from a YAML file?

No. python-dotenv has no YAML support. It only parses `.env`-style `KEY=value` lines, and the code has no YAML parser or YAML option. If you need YAML, parse it yourself with PyYAML, which is a separate package. Then either put the values into `os.environ` or write them out as `.env` text and load that with the `stream=` argument of `dotenv_values` or `load_dotenv`.

```python
# pip install pyyaml python-dotenv
import io, os, yaml
from dotenv import load_dotenv

cfg = yaml.safe_load("DB_HOST: localhost\nDB_PORT: 5432\n")  # or open("config.yml")
env_text = "\n".join(f"{k}={v}" for k, v in cfg.items())
load_dotenv(stream=io.StringIO(env_text), override=True)
print(os.environ["DB_HOST"], os.environ["DB_PORT"])
```

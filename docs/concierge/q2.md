### Q: What does the CLI command dotenv get KEY do when the value in the .env file is an empty string, e.g. KEY= ? What is the exit code?

With `KEY=` in the .env file, `dotenv get KEY` prints an empty line (just a newline) and exits with code 0. It only exits with code 1 when the key is missing or is a bare key with no `=` (parsed as None). Older versions exited 1 for empty values, but that was fixed in 1.2.4.

```python
printf 'KEY=\n' > .env
dotenv get KEY; echo "exit=$?"   # prints an empty line, then exit=0
dotenv get MISSING; echo "exit=$?"   # prints nothing, exit=1
```

**Warnings**

- Behavior before 1.2.4 differed: `dotenv get` exited 1 for empty values (CHANGELOG.md:22). Older installed versions may still do that.
